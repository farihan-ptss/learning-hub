Seni Bina Motorola 68000, Set Arahan & Mod Pengalamatan EASY68K

Penguasaan Bahasa Perhimpunan Motorola 68000 menggunakan simulator EASY68K. Pelajari penggunaan penentu saiz data (.B, .W, .L), format nombor bervariasi, serta mod pengalamatan daftar, ingatan dan penuding.

4.1.1 Definisi & Saiz Data Dalam EASY68K

Set Arahan (ISA) 68000

Set arahan pemproses Motorola 68000 berasaskan seni bina 32-bit dalaman dengan daftar data 32-bit (D0-D7) dan daftar alamat 32-bit (A0-A7).

Bahasa Mesin 68k

Kod biner 16-bit hingga 64-bit yang dihasilkan oleh perisian EASY68K Assembler untuk dilaksanakan secara terus oleh pemproses 68000.

Bahasa Perhimpunan EASY68K

Sintaks arahan berstruktur: OPCODE.SIZE SOURCE, DESTINATION
Contoh: MOVE.L #$12345678, D0

Penentu Saiz Data (Data Size Specifiers) & Format Literal

.B (Byte - 8 Bit)

Mengendalikan 8-bit terbawah (Bits 0-7). Nilai: 0 hingga 255 (Unsigned) atau -128 hingga +127 (Signed).

MOVE.B #100, D0
.W (Word - 16 Bit)

Saiz lalai (*Default*). Mengendalikan 16-bit terbawah (Bits 0-15). Nilai: 0 hingga 65,535.

ADD.W #$00FF, D1
.L (Long Word - 32 Bit)

Mengendalikan keseluruhan 32-bit register (Bits 0-31). Nilai: 0 hingga 4,294,967,295.

MOVE.L #%10101010, D2
Simbol Format Nombor dalam EASY68K:
  • #100 → Nombor Perpuluhan (*Decimal*)
  • #$FF → Nombor Heksadesimal (*Hexadecimal* - didahului simbol $)
  • #@77 → Nombor Oktal (*Octal* - didahului simbol @)
  • #%11001100 → Nombor Biner (*Binary* - didahului simbol %)
  • #'A' → Aksara ASCII (*Character Literal* - dipetik dengan ')
Nota Khas Analisis Register

Bedah Siasat Terperinci: Pembahagian Register 32-Bit (D1 & D2) dan Operasi AND.W / OR.W

Panduan langkah demi langkah untuk memahami bagaimana pemproses Motorola 68000 memecahkan nilai register 32-bit mengikut penentu saiz data (.B, .W, .L) dan kesannya terhadap nilai akhir register.

1 Struktur Nilai $10234AB7 dalam Register D1 (32-Bit)

Setiap register data (D0-D7) mempunyai ruang simpanan 32-bit (8 digit Hex). 1 digit Hex = 4 bit.

10 Byte 3
23 Byte 2
4A Byte 1
B7 Byte 0 (LSB)
8 Hex Digits × 4 bit = 32-bit Lengkap

2 Pembahagian HIGH Word vs LOW Word (16-Bit)

Apabila menggunakan akhiran .W, CPU membahagikan register 32-bit kepada 2 bahagian utama:

$1023 16-bit TINGGI (HIGH)
$4AB7 16-bit RENDAH (LOW - D1.W)

Arahan .W hanya memproses $4AB7 dan membiarkan $1023 tidak disentuh!

Ringkasan Ekstraksi Data mengikut Penentu Saiz (.B, .W, .L)

Penentu Saiz Saiz Bit D1 = $10234AB7 D2 = $264D5E92 Keterangan Digit Hex
.B (Byte) 8 Bit D1.B = $B7 D2.B = $92 Ambil 2 digit Hex paling kanan
.W (Word) 16 Bit D1.W = $4AB7 D2.W = $5E92 Ambil 4 digit Hex paling kanan
.L (Long) 32 Bit D1.L = $10234AB7 D2.L = $264D5E92 Ambil Keseluruhan 8 digit Hex
Kitaran Pelaksanaan Arahan: AND.W D1, D2 Destination: D2
Langkah A: Ambil 16-bit Rendah (.W) D1.W = $4AB7 → %0100 1010 1011 0111
D2.W = $5E92 → %0101 1110 1001 0010
Langkah B: Operasi Bitwise DAN (AND)   0100 1010 1011 0111 ($4AB7)
AND 0101 1110 1001 0010 ($5E92)
-------------------------------
  0100 1010 1001 0010 ($4A92)
Langkah C: Kemas Kini Hasil ke Register Destinasi (D2): Ingat! 16-bit TINGGI D2 (iaitu $264D) **TIDAK BERUBAH**. Hanya 16-bit RENDAH dikemas kini:
D2 Asal: $264D5E92  →  D2 Baru: $264D4A92

4.1.2 & 4.1.3 Mod Pengalamatan EASY68K (Motorola 68000)

Setiap arahan EASY68K menggunakan sintaks Arahan.Saiz Sumber, Destinasi. Berikut ialah 4 mod pengalamatan utama bersama formula Alamat Berkesan (Effective Address - EA):

Mod Pengalamatan EASY68K Format Arahan Sample Formula / EA Keterangan Operasi
1. Immediate (Serta-merta) MOVE.B #100, D0
MOVE.L #$12345678, D1
MOVE.B #'A', D2		 EA = Instruction Stream Data tetap diletakkan terus selepas opcode dalam arahan. Menyokong pelbagai format (#Decimal, #$Hex, #%Bin, #'Char').
2. Data Register Direct ADD.W D1, D0
MOVE.L D0, D3		 EA = Data Register (D0-D7) Data berada terus di dalam daftar data CPU. Capaian terpantas tanpa melibatkan RAM.
3. Address Register Direct MOVEA.L A0, A1
ADDA.W A0, A1		 EA = Address Register (A0-A7) Digunakan khas untuk memindahkan atau mengubah alamat memori di dalam daftar alamat.
4. Absolute Direct (Terus / Mutlak) MOVE.W $1000, D0
MOVE.B D0, $2000		 EA = $1000 / $2000 Alamat memori dinyatakan secara tepat dan tetap di dalam arahan.

4.1.4 Panduan Analisis Arahan: Kenal Pasti Saiz Data, Jenis Data & Mod Pengalamatan

Setiap arahan EASY68K boleh dianalisis berdasarkan 4 langkah utama:

Langkah 1: Opcode

Tentukan jenis operasi (contoh: MOVE, ADD, SUB, MULU, AND).

Langkah 2: Saiz Data

Semak akhiran saiz: .B (Byte/8-bit), .W (Word/16-bit), .L (Long Word/32-bit). *Default ialah .W.

Langkah 3: Format Data

Kenal pasti format: #100 (Perpuluhan), #$FF (Hex), #@77 (Oktal), #%1010 (Biner), #'A' (ASCII), atau Daftar/Memori.

Langkah 4: Mod Pengalamatan

Kenal pasti mod bagi **Sumber (Source)** dan **Destinasi (Destination)**.

Jadual Analisis Lengkap Contoh Arahan EASY68K

Arahan EASY68K Saiz Data & Bit Format / Jenis Data Mod Pengalamatan Sumber Mod Pengalamatan Destinasi
MOVE.B #100, D0 .B (Byte - 8-bit) Nombor Perpuluhan (Decimal) Immediate Addressing Data Register Direct (D0)
ADD.W #$1A2B, D1 .W (Word - 16-bit) Nombor Heksadesimal (#$) Immediate Addressing Data Register Direct (D1)
SUB.L #%11001100, D2 .L (Long - 32-bit) Nombor Biner (#%) Immediate Addressing Data Register Direct (D2)
MOVE.B #'M', D3 .B (Byte - 8-bit) Aksara ASCII (#'Char') Immediate Addressing Data Register Direct (D3)
MOVE.W $1000, D0 .W (Word - 16-bit) Kandungan Memori RAM ($1000) Absolute Direct Addressing Data Register Direct (D0)
MOVE.W D1, $2000 .W (Word - 16-bit) Nilai Daftar Data D1 Data Register Direct Absolute Direct ($2000)
MOVEA.L A0, A1 .L (Long - 32-bit) Nilai Alamat Memori dalam A0 Address Register Direct Address Register Direct (A1)

Modul Rujukan Arahan Utama

Panduan Lengkap Arahan: DIVU, MULU, OR, NOT & AND

Jadual terperinci mengenai cara kerja, saiz data yang disokong, contoh arahan pelbagai mod pengalamatan, dan kesan hasil operasi ke atas register bagi 5 arahan utama ini.

1. AND (Bitwise LOGICAL AND) Saiz: .B, .W, .L

Melakukan operasi DAN bit demi bit antara sumber dan destinasi. Digunakan untuk bit masking (memadam bit tertentu kepada 0).

Sintaks / Format Contoh Arahan Mod Pengalamatan Hasil & Kesan Register
AND.B #Data, Dn AND.B #%00001111, D0 Immediate → Data Register Direct Padam 4 bit atas D0.B (hanya 4 bit bawah kekal).
AND.W Dn, Dm AND.W D1, D2 Data Register Direct → Data Register Direct D2.W = D1.W AND D2.W (High word D2 tidak berubah).
AND.L $Alamat, Dn AND.L $1000, D3 Absolute Direct → Data Register Direct AND 32-bit data RAM $1000 dengan D3.L secara penuh.
2. OR (Bitwise LOGICAL OR) Saiz: .B, .W, .L

Melakukan operasi ATAU bit demi bit. Digunakan untuk set bit (menukar bit tertentu kepada 1).

Sintaks / Format Contoh Arahan Mod Pengalamatan Hasil & Kesan Register
OR.B #Data, Dn OR.B #%10000000, D0 Immediate → Data Register Direct Set bit ke-7 pada D0.B menjadi '1'.
OR.W Dn, Dm OR.W D1, D2 Data Register Direct → Data Register Direct D2.W = D1.W OR D2.W.
OR.L #$Hex, Dn OR.L #$0000FFFF, D1 Immediate → Data Register Direct Set 16-bit bawah D1 menjadi $FFFF tanpa ganggu bit atas.
3. NOT (Bitwise NOT / Invert Bits) Saiz: .B, .W, .L

Menterbalikkan semua bit (0 menjadi 1, 1 menjadi 0 - One's Complement).

Sintaks / Format Contoh Arahan Mod Pengalamatan Hasil & Kesan Register
NOT.B Dn NOT.B D0 Data Register Direct Terbalikkan 8-bit bawah D0 (contoh: %00001111 → %11110000).
NOT.W $Alamat NOT.W $2000 Absolute Direct Terbalikkan data 16-bit dalam lokasi ingatan RAM $2000.
NOT.L Dn NOT.L D1 Data Register Direct Terbalikkan keseluruhan 32-bit register D1.
4. MULU (Unsigned Multiplication) 16-bit × 16-bit → 32-bit

Mendarab dua nombor 16-bit tanpa tanda (unsigned positive numbers) dan menyimpan hasil pendaraban 32-bit lengkap ke dalam register destinasi Dn.

Sintaks / Format Contoh Arahan Mod Pengalamatan Hasil & Kesan Register
MULU #Data, Dn MULU #10, D0 Immediate → Data Register Direct D0.L = (D0.W × 10). Hasil meliputi 32-bit penuh D0.
MULU Dn, Dm MULU D1, D2 Data Register Direct → Data Register Direct D2.L = (D2.W × D1.W).
MULU $Alamat, Dn MULU $1000, D0 Absolute Direct → Data Register Direct Darab data 16-bit dari RAM $1000 dengan D0.W. Hasil disimpan di D0.L.
5. DIVU (Unsigned Division) 32-bit ÷ 16-bit → Hasil (Low) + Baki (High)

Membahagi nilai 32-bit dalam register Dn dengan operand 16-bit. Storan hasil bahagi dan baki dalam register destinasi:
• Low Word (Bits 0-15): Hasil Bahagi (Quotient)
• High Word (Bits 16-31): Baki Pembahagian (Remainder)

Sintaks / Format Contoh Arahan Mod Pengalamatan Hasil & Kesan Register
DIVU #Data, Dn DIVU #10, D1 Immediate → Data Register Direct D1.L ÷ 10. Low Word = Hasil Bahagi, High Word = Baki.
DIVU Dn, Dm DIVU D0, D2 Data Register Direct → Data Register Direct D2.L ÷ D0.W. Hasil bahagi simpan di D2.W (Low), Baki di D2 (High).
DIVU $Alamat, Dn DIVU $2000, D3 Absolute Direct → Data Register Direct Bahagi D3.L dengan nilai 16-bit di lokasi RAM $2000.

Galeri Contoh Kod EASY68K Pelbagai Jenis Data & Operasi

Penerokaan pelbagai kombinasi jenis data (Byte .B, Word .W, Long Word .L), format nombor (#Dec, #$Hex, #%Bin, #'Char'), serta operasi aritmetik dan logik EASY68K.

1. [Data Format] Gabungan Perpuluhan, Hex, Biner & ASCII Literal Data 
* Memuatkan Pelbagai Format Data ke Daftar
    ORG    $1000
START:
    MOVE.B #255, D0         * Decimal (Byte 8-bit)
    MOVE.W #$FF00, D1       * Hexadecimal (Word 16-bit)
    MOVE.L #%10101010, D2   * Binary (Long Word 32-bit)
    MOVE.B #'M', D3         * ASCII Character 'M' (Nilai 77)
    
    SIMHALT
    END    START

Penerangan: Simbol # menandakan nilai tetap. Simbol $ untuk Hex, % untuk Biner, dan ' ' untuk aksara ASCII.

2. [Aritmetik Byte .B] Operasi 8-bit (ADD.B / SUB.B) Saiz Byte 
* Penambahan & Penolakan Saiz Byte (.B)
    ORG    $1000
START:
    MOVE.B #150, D0     * D0 = 150
    MOVE.B #75, D1      * D1 = 75
    ADD.B  D1, D0       * D0 = 150 + 75 = 225
    SUB.B  #25, D0      * D0 = 225 - 25 = 200
    
    SIMHALT
    END    START

Penerangan: Penentu saiz .B hanya mengubah 8-bit terbawah daftar tanpa menjejaskan bit 8-31 pada daftar data D0.

3. [Aritmetik Long .L] Nombor Besar (ADD.L / SUB.L) Saiz 32-Bit 
* Operasi Long Word 32-bit (.L)
    ORG    $1000
START:
    MOVE.L #$000F4240, D0   * D0 = 1,000,000 (Decimal)
    MOVE.L #$0007A120, D1   * D1 = 500,000 (Decimal)
    ADD.L  D1, D0           * D0 = 1,500,000
    SUB.L  #$000186A0, D0   * D0 = 1,500,000 - 100,000
    
    SIMHALT
    END    START

Penerangan: Penentu .L memroses nilai 32-bit secara penuh. Sangat berguna untuk pengiraan alamat ingatan dan nilai nombor berskala besar.

4. [Darab & Bahagi] MULU & DIVU (Unsigned) MULU / DIVU 
* Pendaraban & Pembahagian Nombor Positif
    ORG    $1000
START:
    MOVE.W #120, D0     * D0 = 120 (16-bit)
    MULU   #10, D0      * D0 = 120 * 10 = 1200 (Hasil 32-bit)

    MOVE.L #105, D1     * D1 = 105 (32-bit)
    DIVU   #10, D1      * D1 = 105 / 10
                        * Low Word D1  = 10 (Hasil Bahagi)
                        * High Word D1 = 5  (Baki)
    SIMHALT
    END    START

Penerangan: MULU mendarab 16-bit x 16-bit menjadi 32-bit. DIVU membahagi 32-bit dengan 16-bit, menyimpan **Hasil Bahagi** di 16-bit bawah dan **Baki** di 16-bit atas.

5. [Logik Bitwise] Masking & Invert (AND, OR, NOT) Operasi Bit 
* Operasi Masking & Manipulasi Bit
    ORG    $1000
START:
    MOVE.B #%11111100, D0
    AND.B  #%00001111, D0  * Masking: D0 = %00001100 (Pemadaman Bit)
    
    OR.B   #%10000000, D0  * Set Bit: D0 = %10001100
    NOT.B  D0              * Terbalikkan bit D0
    
    SIMHALT
    END    START

Penerangan: AND digunakan untuk *bit masking* (padam bit ke 0), OR untuk set bit ke 1, dan NOT untuk menterbalikkan bit.
