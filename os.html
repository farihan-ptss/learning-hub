3.1

Pengenalan kepada Sistem Pengendalian

Introduction to Operating Systems

3.1.1 Definisi Sistem Pengendalian dalam Sistem Komputer

Sistem Pengendalian (Operating System / OS) ialah perisian sistem terpenting yang bertindak sebagai antaramuka (interface) di antara pengguna/perisian aplikasi dan peranti keras (hardware) komputer.

Pengguna (User)
Aplikasi (Apps)
Sistem Pengendalian (OS)
Peranti Keras (Hardware)
Tugas Utama OS
  • Menguruskan sumber perkakasan (CPU, Memori RAM, Storan).
  • Menyediakan platform untuk menjalankan aplikasi.
  • Mengurus fail dan direktori penyimpanan data.
  • Menyediakan antaramuka pengguna (GUI / CLI).
Contoh OS Popular

Komputer Meja & Laptop: Microsoft Windows, Linux (Ubuntu, Fedora, Mint), macOS.
Peranti Mudah Alih: Android, iOS.

3.2

Ciri-ciri Sistem Pengendalian (Windows vs Linux)

Explain operating system features

Setiap sistem pengendalian mempunyai reka bentuk dan pendekatan berbeza. Berikut adalah perbandingan mendalam bagi Windows dan Linux mengikut 4 ciri utama:

a

Antaramuka Pengguna & Pengurusan Desktop

Windows

Antaramuka Grafik (GUI) yang seragam, intuitif, dan mudah dipelajari. Menggunakan Start Menu, Taskbar, dan rekabentuk konsisten (Aero / Fluent Design).

Linux

Menawarkan pelbagai Persekitaran Desktop (Desktop Environments - DE) yang boleh dipilih pengguna seperti GNOME, KDE Plasma, dan XFCE. Menyokong Antaramuka Talian Arahan (CLI - Terminal) yang sangat berkuasa.

b

Keserasian Perisian & Aplikasi

Windows

Sokongan perisian komersial yang amat luas. Majoriti permainan video (PC Games), Microsoft Office, dan aplikasi profesional (Adobe Creative Cloud) dibina khas untuk format .exe / .msi.

Linux

Menggunakan perisian sumber terbuka (Open Source) seperti LibreOffice, GIMP. Pemasangan perisian dilakukan melalui Pengurus Pakej (APT, YUM, Snap, Flatpak). Boleh menjalankan fail Windows menggunakan lapisan keserasian seperti Wine atau Proton.

c

Kebolehsesuaian & Fleksibiliti

Windows

Kebolehsesuaian terhad kepada tetapan rasmi OS, tema warna, dan tetapan Registry. Kod sumber adalah proprietari (tertutup).

Linux

Sangat fleksibel dan berkuasa tinggi! Disebabkan sifat Sumber Terbuka (Open Source), pengguna boleh mengubah suai keseluruhan kernel, antaramuka, skrip automatik, dan komponen sistem mengikut kehendak.

d

Keselamatan & Kestabilan

Windows

Sering menjadi sasaran perisian dengki (malware/virus) kerana populasi pengguna yang besar. Memerlukan kemas kini keselamatan berkala (Windows Update) dan antivirus terbina (Windows Defender).

Linux

Kestabilan tahap tinggi (kerap digunakan pada pelayan/server utama dunia). Model kebenaran pengguna teras (Root vs Regular user) menjadikannya sangat selamat daripada jangkitan virus secara automatik.

3.3

Perkhidmatan Sistem Pengendalian (Operating System Services)

Explain operating system services in computer systems

a. Pengurusan & Organisasi Sistem Fail

Menggunakan sistem fail NTFS (New Technology File System) yang menyokong kawalan kebenaran fail, penyulitan (encryption), dan pemulihan jurnal. Juga menyokong FAT32 / exFAT untuk pemacu kilat (USB).

b. Pengurusan Peranti & Sokongan Pemacu

Menggunakan Device Manager untuk memantau perkakasan. Menyokong teknologi Plug and Play (PnP) di mana Windows memasang pemacu peranti (driver) secara automatik apabila peranti baharu disambung.

c. Rangkaian & Kesambungan Internet

Dilengkapi sokongan penuh stack TCP/IP, Network and Sharing Center, sambungan Wi-Fi visual, dan perkongsian fail folder menggunakan protokol SMB/CIFS.

d. Keselamatan & Kawalan Capaian

Mempunyai User Account Control (UAC) untuk menghalang perubahan sistem tanpa kebenaran, Windows Defender Antivirus, BitLocker Drive Encryption, dan Windows Firewall.

a. Pengurusan Sistem Fail & Kebenaran

Menggunakan sistem fail ext4, Btrfs, atau XFS. Kawalan kebenaran ketat berasaskan 3 peringkat: Owner, Group, dan Others serta hak akses Read (r), Write (w), Execute (x) melalui arahan chmod & chown.

b. Pengurusan Peranti & Modul Kernel

Menganggap semua peranti sebagai fail dalam direktori /dev. Memuatkan pemacu peranti secara dinamik sebagai Kernel Modules menggunakan arahan seperti lsmod dan modprobe.

c. Rangkaian & Alat Kesambungan

Dilengkapi alat talian arahan (CLI) berkuasa tinggi untuk rangkaian seperti SSH (kawalan jarak jauh selamat), ip, ifconfig, netstat, serta tembok api iptables / ufw.

d. Keselamatan & Mekanisme Kawalan Capaian

Menggunakan mekanisme kebenaran pentadbir sudo (Superuser Do) untuk tugas sensitif, serta modul keselamatan gred industri seperti SELinux dan AppArmor pada peringkat kernel.
